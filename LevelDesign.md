# Level Design Notes

## Levels

- **10 Pairs**
  - Grid: 4x5
  - Default spacing

- **15 Pairs**
  - Grid: 5x6
  - Adjusted spacing for clarity

- **20 Pairs**
  - Grid: 5x8
  - Scaled-down cards
  - Smaller spacing

## Layout
- Cards are instantiated at runtime and animated into place.
- Category-based image assignment ensures variety.
- Each image appears exactly twice.

## Score
- Time saved as score
