# Card Matching Game 🎮🃏

A simple memory-based card matching game built in Unity. Flip the cards, match the pairs, and win the game!

## Features
- Multiple difficulty levels: 10, 15, or 20 pairs
- Category selection for themed cards
- Smooth rotation-based card flip animation
- Sound effects for actions and matches
- audio can be muted or unmuted
- Clean, responsive UI

## Getting Started

1. Open the project in Unity (version 2021.3.31f1 or higher recommended).
2. Load the `MainMenu` scene.
3. Hit play and enjoy!

## Controls
- Click on cards to flip them.
- Match two identical cards to remove them.
- Use the menu to change difficulty or reset.
